プランの予算を段（気軽に / ふつう / ちょっと贅沢 / 贅沢 / こだわらない）で選ぶ下端の欄で、プラン作成の全部選んだ画面（PlanFlow）の下に固定され、組み立て中は手順と選んだ段の棒に替わる。

渡すもの: 段の列（名前・セルごとの上限 or こだわらない）、値段を持つセル（言葉・棒の色）、選んである段、組み立て中なら手順の進み具合と決まった段の数。段は選んだ好みの店の値段の 20 / 40 / 60 / 80% から作り（1〜4 段 + こだわらない）、値段を持つ好みが無ければ段は出さず決定だけ。

- `.fl-pn`: 下端に fixed・角 24 24 0 0・padding 14 16 8・面 rgba(22,22,26,.86) + blur 18px saturate 1.2・上辺に白 .08 の 1px のハイライト + 上への影。完成すると下へ滑って消える（.5s）。
- 段 `.fl-tier`（radio）: 高さ 34・左右 14・角 17・面なし・泡の絵を伸ばした枠（`--bw` 17）。段の間 6px。1 行 `.fl-ln` = 名前 `.fl-nm`（幅 80・12px 700 fg2）→ 1 人あたりの合計 `.fl-tot`（幅 66・右寄せ 13px 800 白 .8）→ 横の積み棒 `.fl-bar`（高さ 14・隙間 1.5px・角 3・幅 = 上限 ÷ 一番高い段の合計）。
- 棒の色 = セルの色（時間の順に値段を持つセルへ #ffb870 → #82f2d2 → #4fd6ff → #ff86c8 → #b88cff → #7a9cff → #c38bff）。同じ色がセルの頭の印と色の説明にも出る。
- 選んだ段 `.sel`: 高さが伸び（.34s）、面 = `bubble-on`（白 .2）+ `shadow-halo`（枠は泡の絵のまま・角 17 の伸ばした泡が下へ伸びる）。名前 13px fg・合計 15px fg・棒 18px。内訳 `.fl-brk`（最小 62px の格子）= 色の印 8px + 言葉 11px 700 fg2 / 上限 14px 800。
- こだわらない: 合計の所に「上限なし」・棒の代わりに点線（1px dashed 白 .45・右へ消える）・内訳は「値段の上限を付けずに探します。」。
- 決定 `.pl-pill.fl-go`: 幅いっぱい・margin-top 12・16px 800。段を選ぶまで出ない。押すと選ばなかった段が弾け（.32s）てから組み立てへ。
- 色の説明 `.fl-lgd`: 一番下・中央・8px の角 2 の印 + 11px 700 fg2・押せない。
- 組み立て中 `.fl-prog`: 手順 4 つ（13px 700・済み = fg2 + ✓ の泡 / 今 = fg + 小さな泡の絵 `bubble.s.webp` が .9s で回る / 待ち = 白 .42 + 薄い泡の絵（.4））→ 選んだ段の名前 17px 800 +「1 人 ¥13,000まで」12px fg2 → 棒 `.fl-track`（高さ 10・丸・地 白 .08）がセルが決まるたびに伸びる（.6s）。確かめる段では光が流れる。
- 予算を決め直す古いダイアログ（`.tm-money` / `.tm-tiers`・選んだ段の名前が金）は、決めた予算の泡を押して選び直すときにだけ出る。予算の主な UI はこの欄。
- やらない: 段を色の面や色の枠で強調しない（白い面 + パステルの光）。金や赤のボタンにしない。上端に固定しない（固定は下端の欄だけ）。
