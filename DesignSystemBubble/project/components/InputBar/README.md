泡の絵を横に伸ばした 1 行の入力欄（`.pl-field`）で、プランの結果の終わり「変えたいところは？」で、ほかの希望を書いて送る所に使う。
渡すもの: プレースホルダの言葉（`webTripTuneHint`）、入力中の文字、直している間か（送信を止める）。

- 形: form `.pl-field` = flex・gap 8・padding 4px 4px 4px 18px・角丸 999px・面 `raise`。皮 = 共通の伸ばした泡（`--bw` 24）。上の選択肢から margin-top 12。地域選択の上端の入力欄 `.tm-region-q`（高さ 44・`--bw` 22）も同じ作り。
- `:focus-within` = 外に空色のにじみ `0 0 12px rgba(198,230,255,.35)` を足す。
- input: 16px・`fg`・枠なし・padding 8px 0・最大 300 字・`enterkeyhint="send"`。プレースホルダは `fg3`、長ければ右で切れる。
- 右端の送信 = `.pl-bub` 40（上向きの矢印の線の絵 20px）。空のとき / 直している間は `disabled`（不透明度 .5）、文字があると `.pl-bub.on`（泡の中を白 .2 で満たす + `shadow-halo`）。
- 下に `.pl-note`（12px・`fg2`）で送ると何が起きるかを 1 行。
- 変換確定の Enter では送らない（Safari の keyCode 229 を止める）。スマホで入力中はアプリバー `.tn` とプランの下端の帯 `.pl-bar` を隠す。
- やらない: 四角い入力欄・色の枠のフォーカスにしない（フォーカスは空色のにじみだけ）。送信を言葉のボタンや色の塗りにしない。
