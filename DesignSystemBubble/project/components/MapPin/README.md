街の地図（真上から見た 3D の地図）に立てる店のピン・集約・現在地・探す範囲の輪で、テーマ / 百名店 / 近くのお店の場面と、そこから開いた店の詳細の間に出る。
渡すもの: 店ごとの位置とジャンルの絵（無ければ絵文字）、集約の位置と店の数（ジャンルが 1 つならその絵）、現在地、輪の中心と半径（地上の m → 徒歩 / 車の分）、開いている店。

- 泡のピン `.tm-pin.bb`: 要素は高さ 0（下端 = 店の位置）、`.tpb` 42px の泡の中心を店の位置に置く。泡 `.bb` = ジャンルの絵（縮小版 192px）+ 泡の輪 `bubble.webp`（106% ではみ出させる）、下地 `rgba(0,0,0,.35)`、影 `0 3px 8px rgba(0,0,0,.55)`。絵の無いジャンルは 22px の絵文字。
- 絵の無い店 `.tm-pin`: 白い軸（2×16・影）の上に 20px の金の玉（白 2px の縁）。
- 集約 `.tm-pin.cl`: 30px の泡（`bubble.s.webp`・面 `rgba(0,0,0,.3)`）の中心に店の数（12px 800 白・影）。ジャンルが 1 つのとき `.cl.img` = 36px でその絵を `brightness(.62)` に暗くして数 13px。集約は店のピンより手前、南のピンほど手前。
- 見せ方: ピンは場面の間だけ（`html.tm-pins` / `tm-hyaku`）、少し透かして `.85`・.25s で出入り。
- 開いた店 `.tm-pin.on`: 大きさも光も変えず、泡に白 2px の枠だけ（`0 0 0 2px #fff` + 影）、一番手前。
- 現在地 `.tm-here`: 16px の白い点（小さい泡の絵 `bubble.s.webp` + 白 .85 の面 + 水色・桃のにじみ）+ 44px の泡の輪が .4 → 1.6 倍に広がって消える（2.4s ease-out・繰り返し）。
- 探す範囲の輪 `.tm-ring`: 見えている地図の真ん中に直径 = 画面幅の 80% の円（白 1.6px `.95`・床 白 `.06`・水色の内外のにじみ）+ 中心の白い点 12px + 中心から上端までの破線（白 `.5`）。下のシートの高さが変わると中心が .35s で滑る。ピンが立っていて真上から見ている間だけ。
- 分のカプセル `.tm-rng`: 輪の上端に中心を合わせる。高さ 32px・角 999px・皮は泡の絵を伸ばしたカプセル（`--bw` 16）・面 黒 .45 + blur 6px、移動のアイコン 18px + 15px 700「10 分」。押すと探す範囲のポップアップ。店の詳細の間は真ん中に押せないカプセル（`.cap` = 分 + 距離 12px 600 `fg2`）と、真ん中から店への点線（白 `.92`・2px・`1 6` の点・水色の影）。
- やらない: ピンに店名を出す。ピンに器やとがった先を付ける・泡を積み重ねる。色の付いた点で現在地を示す。filter: drop-shadow で影を落とす（影は泡の box-shadow）。
