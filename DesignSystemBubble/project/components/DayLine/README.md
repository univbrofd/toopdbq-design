プランの 1 日を横長の写真（dayLine.webp）に敷き、時刻・段の名前・選んだ答えの顔を重ねる帯で、プラン作成（時間帯ごとの質問 / 全部選んだ / 組み立て中）と開いたプランの上端に出る。

渡すもの: プランの段（3 時間ごとの段とプランの時間の重なり・60 分以上。例 10:00〜24:00 → 午前 10–12 / 昼 12–15 / 午後 15–18 / 夕方・夜 18–21 / 夜 21–24）、聞いている段（無ければ .done）、段ごとの顔（泡の絵か店の写真 + 言葉）、明日なら「明日」。

- 構造: `.tm-ask`（padding-top 7・文字に黒い影）→ 題 `.tm-ask-h`（24px 800・行 40）→ `.al`（左右 -16px で画面の幅いっぱい）→ `.al-img`（高さ = 上の余白 + 帯 + 32、margin-top を負にして題の裏から画面の上端まで敷く・下端 32px は mask で地図へ透ける）。
- 位置: 左端 = プランの始まりの手前の 3 の倍数の時刻、右端 = 終わり、左右 PAD 12。時刻 → 絵の割合は折れ線 [[6:00,.04],[12:00,.29],[18:00,.53],[24:00,.80],[翌6:00,1]]、絵は横 3 : 縦 1。帯の高さ = min(102, 絵の高さ)。写真は `background-size / position` を inline で指定。
- 時刻 `.al-t`: 3 時間ごと（9・12・15…・24 を越えたら「翌1」）、11px 700・白 .8・帯の上端 + 7px。明日のプランは左端に `<em>明日</em>`（`.al-t.l`）。
- 段 `.al-seg`: 角 14・名前 `.al-n` 12px 700 白 .8（top 27）。境は 1px の線 `.al-bd`（白 .22・プランの両端 `.end` は .38）。
- 聞いている段 `.cur`: 名前 15px 800 白（top 25・はみ出して可）・写真はそのまま。ほかの段とプランの外は `.al-dim`（黒 .56 + blur 3px + saturate .75）。幕の移動 .45s。
- 顔 `.al-a`（top 49）: `.al-f` 30px の丸（写真 + bubble.s.webp の泡の縁）+ 言葉 11px 700（1 行・…）。聞いている段には出さない（開いたプランだけ出し、`.pl-ask` で白い縁 + 空色 / 桃の光）。
- 全部選んだ `.al.done`: 段の幕が消え、プランの外だけ暗い。
- 組み立て中: `.al-sweep`（幅 96・空色 → 白 .34 → 桃の光が 2.4s で横切る・screen）、今の段 `.work`（白い光で満ち inset 1px 白 .7）、決まった段 `.res`（顔が店の写真・白 .75 の縁 + 空色の光）。
- 押すとその段を選び直す（映画の段は回を選び直す）。focus は inset 1px 白 .7 + 空色の光。
- やらない: 段を枠線や色の塗りで囲わない（強調は写真そのまま + 周りの幕）。作成中の上端に fixed / sticky を使わない（開いたプランの `.pl > .pl-ask` だけ sticky）。色付きのボタンを載せない。
