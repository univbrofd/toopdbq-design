最初の画面の地域選択で、真上から見た地図に区画の四角と画面の真ん中に固定の探す範囲の輪だけを重ね、地図を動かして輪の置き場所を決めて「エリア決定」で決める全画面の層。
渡すもの: 地図の今の見え方（区画の緯度経度を画面に写す）、区画ごとの店の数・地名（geohash 1〜6 桁・`regions.ts`）、地名の索引（入力欄に触れた時に読む）、現在地（右下の泡を押した時だけ聞く）。
- `.tm-region` は地図 `.tm-map` と同じ枠に absolute で重ね、指は地図へ通す（pointer-events: none）。開いている間は `html.tm-areas` で気分の泡・ナビ・シートを隠す。アプリバー・ロゴは出さない
- 上端 `.tm-region-hd`（safe-top + 2・裏に黒の放射のぼかし .6→0）の入力欄 `.tm-region-q`: 幅 min(100vw − 88, 360)・高さ 44・角 999・地 `raise`・皮は泡の絵を伸ばした入力欄（`--bw` 22・InputBar と同じ）、16px・placeholder `fg3`「地域をさがす」、虫眼鏡 18px `fg2`。focus で `0 0 12px` 水色のにじみ
- 候補 `.tm-region-hits`: 同じ幅・下 8・余白 6・角 24・地 `sheet` + 内側 1px `line`。行は高さ 44 のカプセル、地名 16px 700 + 上の地域名 13px `fg2`。押した行 = 白 .14 + 白 .7 の 1px の輪 + 水色のにじみ。無い時は 14px `fg2`「当てはまる地域がありません」。最大 6 件、地名は「・」の前・7 字まで
- 区画 `.tm-region-cell`（SVG の四角・傾いている間は台形）: 塗り rgb(214,216,222)・濃さ = 0.02 + 0.1 × log(1+店の数) / log(1+画面の最多)、縁 rgba(255,255,255,.13) 0.6。地名は区画の中心に 600・白 .5・黒 .6 の 2.5px の縁取り、大きさ = min(16, 高さ × .34, 幅 × .86 / 字数)、8px 未満なら出さない。段は区画が画面で 36px 以上になる一番細かい段
- 区画を軽く押す（10px・500ms 以内）とその区画が輪に収まる所へ寄るだけ（決めない）。寄った区画 `.on` = 縁 白 .85・1.4、地名 白 .92。指で 0.3 段以上拡大・縮小するか、輪の真ん中が区画の外へ出ると消える
- 輪 `.tm-ring`: 画面の真ん中・直径 = 画面幅の 80%。`.r` 白 .95 の 1.6px + 床 白 .06 + 水色のにじみ、`.l` 中心から上端への 1px 破線 .5、`.c` 白い点 12px + 4px の輪。所要時間のカプセルはここでは出さない
- 下端 `.tm-region-go`「エリア決定」: bottom = safe-bot + 6・高さ 52・最小幅 220・左右 40・皮は泡の絵を伸ばしたカプセル（`--bw` 26）・地 rgba(0,0,0,.3) + blur 6px・16px 700・字間 .04em。入力欄の下の駅のチップ `.tm-region-picks button`（高さ 34・`--bw` 17・黒 .45 + blur）も同じ皮で、選んだ駅は `bubble-on` + `shadow-halo`。押すと scale .97、決めている間 aria-busy = 不透明度 .7
- 右下 `.tm-locb`（right 16・決定の列の 1 つ上）= 共通の泡 52px（bubble.webp + rgba(0,0,0,.18) + blur 6px）に方角のアイコン 22px（白 .85）。位置の許可を聞いている間 `.wait` = .8s で .55 まで明滅
- やらない: 上端に fixed / sticky を置かない（edge-to-edge）。区画を色や太い枠で目立たせない（目安として薄く並べるだけ・店は輪の中から探す）。区画を押しただけで決めない。赤・黄・青のボタンを使わない
