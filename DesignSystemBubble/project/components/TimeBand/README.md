プランの時間（から / まで）を、1 日の写真を縦に敷いた帯の上で 2 つの泡を上下に動かして決める全画面のダイアログで、プラン作成の問いの後（と、決めた時間の泡を押して選び直すとき）に出る。

渡すもの: 範囲 [から, まで]（分・最初は 9:00〜24:00、今日もう 9 時を過ぎていれば次のちょうどの時から 24:00）、戻れるか（最初の設定で前の問いがあるときだけ左上の戻る）、明日のプランになるか。

- `.tm-dlg`: 画面いっぱい（absolute inset 0・padding 16）、板なし。裏の街と泡を blur 16px + 黒 .35 でぼかす。開くとき .2s のフェード、箱は .3s でふくらむ。
- 箱 `.tm-dlg-box.tm-when`: 左右の余白を打ち消して画面の幅いっぱい。上 50px から題、下 116px は決定の泡の場所。題 `h2`「時間は？」26px 800・字間 .02em。明日なら下に `.tm-sub`（13px fg2）「明日」。
- 帯 `.tb`（泡の径 `--kb` 68px）: 題と決定の間の高さを全部使う（最小 240）。上端 = 朝 6:00 → 下端 = 翌 6:00 で 1 時間が同じ高さ。写真 dayBand.webp は縦を全部見せ（auto 100%）、左右の余りは同じ写真の blur 22px に溶かす。
- 範囲の外 `.tb-dim`（黒 .62）・境 `.tb-line`（1px 白 .92 + 白い光 8px）・左の縁の時刻 `.tb-h`（3 時間ごと 9 つ・11px 700・白 .8・8px の目盛り）。
- つまみ `.tm-bub.tb-knob`（68px のシャボン玉・線の上の真ん中）: 時刻 `b` 15px 800（24 時を越えたら「翌0:00」）+ `small` 11px 700 fg2「から」/「まで」。重なるほど近いと `.tb.cl` で左右へ 40px ずつずれる（.25s）。
- 操作: 帯を押すと近い方の泡がそこへ跳ぶ・泡はつかんだ所から相対に動く・30 分刻み・1 時間以上・開始は 23:30 まで・矢印キーで 30 分。
- 決定 `.tm-bub.tm-done`: 104px（画面で一番大きい泡）・箱の下端の中央・「決定」19px 700 字間 .06em。押すと弾けて閉じる（.3s）。最初の設定で裏を押すと揺れる（.55s）・決め直しなら裏を押すと閉じる。
- やらない: 板やカードの面を敷かない・input[type=range] を使わない（泡がつまみ）・範囲を色で塗らない（外を暗くするだけ）・色付きの決定ボタンにしない。
