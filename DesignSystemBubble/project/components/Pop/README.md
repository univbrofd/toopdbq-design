泡が弾ける瞬間。押した泡は 0.11 秒でふくらんで消え、縁から白っぽく透き通ったパステルのしぶきが散り、泡の絵そのものが広がって薄れる。選ぶ・決める・閉じるの手応えはすべてこれで返す。

使う所: 気分の泡を押す、決定の泡、場面の切り替え（全部弾いてから次を湧かせる）、大きな泡の右上の針（全部割れる）。

渡すもの: 泡の中心と半径、速さ（投げた泡はその向きにしぶきが流れる）。

- ふくらむ: 半径 × (1 + 経過 × 1.1)、0.11 秒で消える。
- 白い光: 消える瞬間に泡の中を白 .14 が満たし、0.16 秒で抜ける。
- しぶき: 22 + 半径 / 3 粒。縁（半径 × .92）から外へ 120〜380 px/s、重力 520、減速 e^-1.8t、寿命 .45〜.9 秒。
- しぶきの色: 4 割が白、残りを `pop-pink` / `pop-peach` / `pop-mint` / `pop-sky` / `pop-lilac` の色相で等分。泡の中身の色は使わない（同じ色ばかりにならない）。
- 透明度は粒ごとにばらつかせる（一定にしない）: 白 .25〜.9、色 .12〜.52。白い芯はその粒の透明度 + .15〜.4（最大 .95）。地の街や写真が透ける粒と、はっきり光る粒が混ざる。
- 白の半分は小さな光の粒（きらめき・半径 .8〜2px）。ほかは 1.6〜4.4px の柔らかい点（白い芯 → 色 → 透明）で、色の粒の 4 粒に 1 粒は小さな泡のかけら（`bubble.s.webp` を粒の 1.7 倍の半径で）。残りの寿命に合わせて薄くなる。
- 輪: 泡の絵（`bubble.webp`）が縁から 1.45 倍まで 0.45 秒で広がる。不透明度 .6 → 0。図形の虹の輪は描かない。
- `prefers-reduced-motion` では弾けた後の 1 枚だけ見せ、動かさない。
- やらない: 単色のしぶき、全部の粒を同じ透明度にする、不透明な色の粒、泡の中身の色でしぶきを塗る、火花のような尖った形。
