お店 1 軒の写真セルで、一覧のシート・保存したお店・店の詳細の「ほかのお店」・プランの時間帯の候補で同じ 2 列（Pinterest 形式）に並ぶ。
渡すもの: 店名・表紙の写真とその比（ar）・メニューの写真（最大 3 枚）・種類・値段・総合評価・距離（m）・営業中か（true / false / 不明）と次に開く時刻。プランでは いいねの数と自分が押したか・いちばん多いか。

- 並び `.ts-pins`: flex 2 列（`.ts-col`）、列の間も縦も 4px、`margin: 14px -12px 0` で画面の端から 4px。高さの低い列へ順に積む（行で揃えない）。
- セル `.ts-pin`: 黒い面 `linear-gradient(135deg, #000 30%, sheet)` + 1px の白い枠線（`to top right` で左下 `.6` → 右上 `.08`）、角 4px、下の余白 8px、押すと `scale(.98)`（.12s）。
- 表紙 `.ph`: 写真の実寸の比（9:16〜16:9 で切る）、写真は隙間・角なしで敷き詰め（角丸はセルの切り取りだけ）。読み込み前は `raise`。
- 写真の頭 `.hd`（上 4px・左右 4px）: 左 = 営業中の点 `.glow`（7px・`rgba(79,240,138,.75)`・影 0 0 3px）/ 閉まっていれば開く時刻 `.opens`「11:30~」、右 = 移動の分 `.d`（徒歩 / 4 km 以上は車のアイコン + 分）。札は 11px 700 白・面 `rgba(0,0,0,.4)`・角 999px。
- メニューの写真 `.mi`: 1 枚目 `.m1` は実寸の比で幅いっぱい、残りは `.m2` = 2 列の正方形（1 枚なら 2:1 の横長 1 枚）。
- 店名 `.t`: 写真の下に明朝（`font-serif`）10px 600、1 行で切る（…）。
- 行 `.m`: 11px `fg2`、種類 `.g`（縮んで …）・「￥6,000~」・右端に総合評価 `.rt`（700 白・★ 11px だけ `accent`）。
- 写真なし `.ts-pin.bare`: 枠は `raise2 → raise` の斜めのグラデーション（150deg）、店名を枠の真ん中に 15px 700 `fg`、比は 4:3。
- プランの候補 `.ts-pinw`: 写真の右下（`--ar` から計算）に いいね `.pl-like`（28px・泡の絵を伸ばした皮 + 黒 `.45`・ぼかし 6px、押すと `.on` = `bubble-on` + `shadow-halo`）。いちばん多い店は `.lit` = `0 0 0 1px rgba(255,255,255,.55)` + 水色・桃のにじみ（.3s）。候補は営業中と値段を出さない。
- やらない: 店名をセルの一番上や表紙とメニューの写真の間に置く。白い面 + 黒い文字のセル・泡の絵の枠。色の面や色の枠で強調する（強調は白い光 + パステルのにじみだけ）。金は ★ だけ。
