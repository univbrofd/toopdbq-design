下から出る板で、街の地図の上の店の一覧（最初の画面・テーマ・百名店）と店の詳細のシート、プランの共有に使う。
渡すもの: 段階（short / middle / tall / full）、頭の行（戻る・選んだジャンルの顔・見出し・並び）、中身（店のセルの 2 列など）。共有はプランのリンク。

- 一覧のシート `.ts-sheet`: 上の透明な余白 `.ts-sky`（高さ = 画面 − 段階の高さ・指は裏の地図へ通す）+ 板 `.ts-panel`（`sheet`・角 10px・影 `0 -8px 30px rgba(0,0,0,.45)`・下の余白 40px + アプリバーの泡の分）。
- 段階 `data-sheet`: short = `(146px + 58px) × 2/3`（136px・頭と一覧の頭）/ middle = 画面の 64% / tall = 76.8%（店の詳細のシート）/ full = 文書のスクロールで板が上端まで上がる（段階の値は変えない）。余白の高さは .3s で滑らせ、地図に入ると板が下からせり上がる（.42s）。
- 板の上辺: 一覧のセルと同じ 1px の白いグラデーション（左下 `.6` → 右上 `.08`・角の丸みで消える）。
- 頭の行 `.tm-hs-hd`（高さ 56・grid 3 列）: 左 = 戻るの泡 `.tm-bub.tm-hs-back`（40px）/ 中央 = 選んだジャンルの顔の重なり `.tm-hs-pick`（26px の泡を 8px 重ね・4 つ以上は小さな泡 2 粒）+ 見出し（明朝 20px 800）/ 右 = 並び `.ts-sort`（32px・`raise`・12px 600・アイコン 14px）。板が上端に届くと頭は留まり `.stuck` = `rgba(22,22,26,.94)` + ぼかし 14px。
- 板の右上の外に現在地へ戻る泡 `.tm-hs-here`（48px・板と一緒に上下）。つまみはこのシートには出さない。
- 並びのメニュー `.ts-sort-pop`: `sheet`・枠 `line`・角 16・影、行 14px（11px 12px）・アイコン 18px `fg2`、選んだ行 = `raise2` + 700（アイコン: テーマのシートは白・一覧のシートは `accent-text`）。頭が画面の下半分なら上へ開く（`.up`）。
- 一覧のシート（Shops）: つまみ `.ts-grab`（38×4・`fg3`）+ `.tp-top`（題 18px 800 中央・右に並び）。
- 共有 `.pl-sheet`: 幕 `.pl-sheetbg`（黒 `.5`・押すと閉じる）、板 `sheet`・角 26px・余白 10px 20px 24px・高さ 86% まで、つまみ 36×4 白 `.25`、題 22px 800、説明 14px `fg2`、リンクの行 `.pl-link`（`raise`・白 `.18` の内枠・角 999px・15px で …）+ コピーの泡 `.pl-bub`、送る `.pl-pill.wide`（50px）。.3s で下から上がる。
- やらない: 上端に固定した見出し・バー（full でも頭は板の中の sticky で、板が上端に届いたときだけ留まる）。板に backdrop-filter を掛ける（長い板が真っ黒に描かれる）。一覧の板の角を 10px より丸める（26px は共有の板だけ）。
