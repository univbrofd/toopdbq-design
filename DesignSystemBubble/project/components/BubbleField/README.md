最初の画面の泡の欄（`.tm-field` の canvas）で、見出しの玉「何したい？」・百名店の大きな玉・操作の玉「プランを考える」を中央に三角に置き、気分の玉（写真入り）を画面いっぱいに漂わせる。
渡すもの: 見出しの言葉（地域を選んだ後は無し）、気分の玉の並び（よく使われそうな順・言葉・中身の絵 192px か絵文字・`small` / `top`）、`big` の玉、操作の玉（言葉 + 絵）、漂う範囲の下端。

- 玉の絵: 中身の写真を半径 ×.98 の丸で切り抜き、中央ほど暗く（radial 黒 .5 → .28（70%）→ .08）、上に泡の画像 `bubble.webp` を半径 ÷.94 で重ねる。見出しの玉は絵なし（泡だけ）。絵の無い玉は絵文字（半径 ×.42）を上に、言葉を少し下に。
- 言葉: 中央・白・700・影 `rgba(0,0,0,.85)` blur 6。大きさ = 半径 ×.28（見出し .34・操作の玉 / 2 行の言葉 .32）で、幅 半径 ×1.6 に収まるまで縮める。訳文のゼロ幅スペースの所で折る。
- 大きさ（画面幅 W）: 見出し・操作・big = W ×.215（2 つ並ぶので `(W/2 − 8) ÷ 2.04` まで）。漂う玉 = √(.56 × 欄の面積 ÷ (玉の数 × π))（上限 W ×.2・見出しの .9 倍）× .94〜1.06。`top` .85 倍・`small` .7 倍。入り切らなければ .97 倍ずつ縮める（.62 まで）。
- 配置: 百名店（big）を中央の左・操作の玉を右（中心の離れ 半径 ×2.08）、見出しの玉はその 2 つの上（半径 ×1.72）。漂う玉は画面全体に散らし、互いに 3px・端から 8px 空け、ロゴの下から下端のボタン（アプリバー・移動手段・現在地）の 16px 上までに置く。重ねない。
- 動き: 開いた直後のロゴが消えると、全部が落ち着き先でその場でふくらむ（見出しが先・ほかは .1 秒後）。漂い・ぶつかり・ドラッグで投げられ、押すと弾けて（.11 秒・泡の絵が広がって薄れる輪と白〜パステルのしぶき）選んだ玉は消え、子の玉が湧く。玉の無い所に触ると裏の地図（地域選択）へ。
- 地域を選んだ後: 見出しの玉は出さず、左上に地域名（AreaCrumb）・右上に共有の泡。玉はスケッチの決まった位置（slots）に置き、地域の円の縁の 36px 下まで漂う。
- 読み上げ用に見えない `.tm-sr` に同じ操作の button を置き、`h1` は opacity 0（見出しは玉が担う）。
- やらない: 玉に色の塗り・色の縁を付けない（中身は写真、縁は泡の画像だけ）。言葉を金・黄にしない（白だけ）。右下に保存の泡を置かない（保存は下端の中央のアプリバー）。上端に fixed のロゴやヘッダーを置かない。
