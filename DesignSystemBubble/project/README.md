Toopdbq は、夜の街の上にシャボン玉が湧く世界観だけで作る。黒い地、写真を閉じ込めた泡、白い光、泡の膜のパステル。強調も選択も決定も泡で表し、色の付いた枠・ボタンは使わない。ここにあるのは web（`site/`）が今使っているデザインだけで、`components/bundle.css` は web の実際の stylesheet をそのまま写している。

## 使い方

- 画面は `components/bundle.css` の**実際のクラス**で組む（例: 泡 `.tm-bub`、カプセル `.pl-pill`、チップ `.pl-chip2`、入力欄 `.pl-field`、一覧のセル `.ts-pin`、店の欄 `.dk`、1 日の帯 `.al`、段のカード `.tm-ask-card`、ジャンルのセル `.tm-gd-r`、アプリバー `.tn`）。各部品の README とプレビューのマークアップをそのまま写すと web と同じ見た目になる。
- 色と書体は `tokens.css` の変数（`var(--bg)` `var(--fg2)` `var(--font-serif)` …）。新しい値を足すときもまず既存のトークンから選ぶ。
- ボタンを新しく作るときは、丸なら `.bub`、文字なら `.bubx` を付けて中にアイコン・文字・写真を置く（下の「泡だけで作る」）。泡の皮を自分で描かない。
- 画像は `components/img/` に同梱: 泡の輪 `bubble.webp`（小さい顔用 `bubble.s.webp`）、1 日の写真の横版 `dayLine.webp`・縦版 `dayBand.webp`、時間帯ごとの写真 `bands/{early,morning,noon,afternoon,evening,night,late,dawn}.webp`、ジャンルの顔 `faces/`、店の写真の見本 `sample/`。

## 言葉

- **日本語が第一言語**。短い名詞か体言止めで話す: 「何したい？」「この流れで組みます」「この時間帯のほかの候補」「いいね」「共有」「決定」「もっと見る」。敬体の長文は導入文だけ: 「時間帯ごとに、行きたいお店にいいね。いちばん多いお店がプランに入ります。」
- 二人称は書かない（主語を省く）。
- 数字は半角で `tabular-nums`。時刻は `18:00`、範囲は `18:00〜21:00`、日をまたぐと `翌1:00`、金額は `¥5,000`、距離は「徒歩 6 分」「車で 12 分」のように単位の前に半角空白。
- 絵文字はジャンルの絵が無いときの顔と、予算の 💰 だけ。文の飾りには使わない。
- 英字は先頭だけ大文字（Toopdbq / Instagram）。全部大文字にしない。
- エラーは何が起きたかと次の一手を 1 文ずつ。

## 地と層

- 配色は **ダーク 1 つだけ**（`bg` #000）。端末のライト設定に追従しない。泡の輪もロゴも黒地用の 1 組だけ。
- 一番下は夜の街の 3D 地図（MapLibre の dark）。その上に泡（canvas）、その上に下端のシートと欄、最前面に下端中央のアプリバー（`.tn` = ホーム / プラン / 保存の泡 3 つ）。
- 面は `bg` → `raise` → `raise2` の 3 段と、シートの `sheet`。それ以上の段は作らない。プラン一覧の行は `raise2` の面に `radius-14`。
- 写真や地図の上の文字と薄い面は白に透明度を足して作り、スクリムは黒（中心ほど濃く端が透ける放射 `.66 → .42 → .12`、店の欄は下ほど暗い縦）。
- **上端に fixed / sticky を置かない**（iOS Safari のバー裏の描画が止まる）。例外は開いたプランの上端（地区 + 1 日の帯）だけ。固定するのは下端の欄・シート・アプリバー・知らせ。

## 泡だけで作る（ボタンは全部、泡の絵）

押せるものは全部、泡の絵 `img/bubble.webp` を下に敷き、その上にアイコン・文字・写真を置いて作る。FAB もアイコンボタンも文字のボタンもチップも入力欄も同じ絵。**図形で泡を描かない**（放射グラデーションの照り・conic の虹の縁・白い枠線・inset の線は使わない）。

- **丸い泡**（`Bubble` = `.bub` / `.tm-bub`）: 円に泡の絵を 100% で敷く。面は黒 .18 + `backdrop-filter: blur(6px)`。直径は 操作 48（`.tm-bub`）/ 戻る・閉じる 40（`.pl-x`）/ 共有 44（`.tm-share`）/ 店の欄 40（`.dk-btn`）/ 右下の方角・地図 52（`.tm-locb` / `.tm-homemap`）/ アプリバー 52（`.tn`）/ 決定 104（`.tm-done`）。
- **伸ばした泡**（`Button` = `.bubx` / `.pl-pill`・チップ・いいね・入力欄・地図の上の札）: 同じ絵を 9 スライスで横に伸ばす = `::before { border: var(--bw) solid transparent; border-image: url(img/bubble.webp) 49% fill / var(--bw) / 0 stretch }`。輪の太さ `--bw` は**高さの半分**（高さ 40 → 20・50 → 25・34 → 17）で、両端が半円 = 丸い泡を横に引き伸ばした形になる。皮は共通のルール 1 つ（`bundle.css` の `:is(.bubx, .pl-pill, …)::before`）で、部品は大きさ・余白・面・`--bw` だけを持つ。
- 面: 地図や写真の上に浮かぶものは黒 .18〜.45 + `blur(6px)`、シートの上のチップは面なし。静か（`.quiet`）は輪を不透明度 .55 に薄めて面なし。
- **写真の泡**（`.pl-bub`・帯の顔 `.al-f`）: 写真を内側 98% に丸く切り抜き、輪を `inset: -3%` で縁に合わせる。気分の泡は中央を `.5 → .28 → .08` で暗くして白 700 の言葉を載せる。
- **カードと行**（予算の段 `.fl-tier`・映画の回 `.cm-b`・ジャンルの行 `.tm-gd-r`）も同じ伸ばした泡の枠で囲む。角は輪に合わせて丸める（`border-radius` = `--bw`: 段 17・回 14・ジャンルの行 24）。写真の上に枠を描く（`::before` を手前に）。選んだ = 面を `bubble-on`（写真で埋まるカードは外の `shadow-halo` だけ）。
- **行の中のアイコンと文字のリンク**も泡: 下書きの × `.dr-x`・投稿の … `.fd-more`・店の欄の三角 `.dk-more`・共有 `.tm-hs-share` は丸い泡、「もっと見る ›」「移動を変える」「このセクションを分ける」・区切りの時刻 `.sx-tm` は伸ばした泡。食事のスイッチ `.sx-tg` は外も中の棒も泡の絵で、つまみは小さい泡（オンは棒が白く満ちる）。
- 横スクロールのチップの列は、選んだ泡のにじみが切れないよう上下に 8px 余白を足し、外の位置は負の margin で戻す（`.sw-days` / `.tm-region-row` / `.fd-chips`）。
- **小さな印**（参加者の泡 `.pg-bub` / `.fd-bub`・チェック `.sx-ck`・件数の札・組み立ての手順の印・現在地の点）も小さい版の絵 `img/bubble.s.webp`（96px）を敷いて作る。読み込み中の印は絵が回る。
- **地図のピン**（`.tm-pin`）: 白い軸の上に写真の泡（ジャンルの絵）。絵の無い店は 20px の金の玉。
- 泡と写真の上の白い文字は黒い影 `0 1px 3px rgba(0,0,0,.95), 0 0 6px rgba(0,0,0,.7)` を持つ。

## 強調は光で

- 強調・選択・今いる所は「泡の絵の中が白で満ちて、外へにじむ」で示す: 面を `bubble-on`（白 .2・web の `--bub-on`）にし、`shadow-halo`（`pastel-sky` 14px + `pastel-pink` 26px のにじみ・web の `--bub-glow`）をまとう。白い枠線や放射の照りは足さない（縁は泡の絵の縁のまま）。選んだチップ、選んだ駅・日・移動手段、いいね済み（`.pl-like.on`）、送れる送信の泡、決定、今の時間帯の顔はすべて同じ光り方。
- 大きさでも強調する: 決定は 104、見出しと操作の泡は画面幅の 37%。
- **金は評価の ★（`accent`）と、絵の無い店の地図のピンの玉だけ**。ボタン・枠・塗り・選択には使わない。
- 使わない色: 赤（エラーも淡い桃 `err`）、青のボタン。リンクは `link`。意味を持つ小さな色だけ残す: 営業中の光る点（`open-dot`）、口コミの良い点 / 気になる点（`voice-*`）、予算の棒の段ごとの色。

## 時間帯

- 1 日は 3 時間の段で考える: 早朝 6–9 / 午前 9–12 / 昼 12–15 / 午後 15–18 / 夕方・夜 18–21 / 夜 21–24 / 深夜 24–27 / 明け方 27–30。プランの時間と重なる 60 分以上の段だけを使う。
- 時間は色の帯でなく**写真**で見せる: 横の 1 日の帯（`DayLine` = `img/dayLine.webp`）、縦の時間帯（`TimeBand` = `img/dayBand.webp`）、段ごとの写真（`img/bands/`）。今の段だけ写真をそのまま見せ、外は黒 .56 + 弱いぼかしで沈める。区切りは白の細い線。
- 段のことは段のカード（`AskCard`）で話す: 段の名前 + 時刻、2 行目に言葉。

## 弾ける

選ぶ・決める・閉じるの手応えは、泡が弾けることで返す（`Pop`）。押した泡は 0.11 秒で 1.1 倍までふくらんで消え、縁から白とパステルのしぶきが散り、泡の絵そのものが 1.45 倍まで広がって薄れる。場面を替えるときは全部弾いてから次を同じ湧き方で出す。

## 文字

- 書体は端末の `body`（Hiragino Sans → Noto Sans JP）。同梱しない。明朝（`serif`）は 地区の名前（`.tm-ring-name`）、一覧のセルの店名（10px 600）、テーマのシートの題（20px 800）だけ。
- 見出しは 800、ボタンとラベルは 700、本文は 400。文字の色は `fg` / `fg2` / `fg3` の 3 段（`fg3` は 13px 以上だけ）。

## 余白と形

- ページは `gutter` 16 の 1 列、最大 `column` 640。一覧の写真だけ 4px まで詰めて 2 列に敷き詰める。
- 角は役割で決める: セル `radius-4`、写真 `radius-8`、一覧のシートの上の角 `radius-10`、段のカード・帯の段・一覧の行 `radius-14`、予算の欄 `radius-24`、共有と映画の回のシート `radius-26`。押せるものは `radius-pill` か `radius-circle`。
- 枠線は `line`（白 .12）のヘアライン。一覧のセルだけ左下 `cell-edge-hi` → 右上 `cell-edge-lo` の白の 1px。泡の縁は泡の絵の縁だけ（図形の縁は描かない）。
- 影は下端のシート（`shadow-sheet` / `shadow-panel`）と地図のピン（`shadow-pin`）だけ。カードに影を付けない。
- 下端の欄はアプリバーの分（`nav` 58）と `safe-area-inset-bottom` だけ上に置く。

## 動き

- 湧く: 中央から昇って輪に落ち着く（0.5 秒でふくらむ）。弾ける: `Pop`。シートは `.34s cubic-bezier(.2,.8,.2,1)` で下から。
- タブの切り替えは画面全体が横に滑る `.34s`。一覧の写真 → 詳細の頭は view-transition で枠だけ変える `.42s`。開いたプランは帯の段を押すか横になぞると隣の時間帯へ。
- 組み立て中は帯を光が横切り（`.al-sweep`）、今決めている段が光で満ちる。
- `prefers-reduced-motion` では泡の跳ねとしぶき、光の走りを止める。

## アイコン

- インラインの SVG、`viewBox 0 0 24 24`、`stroke: currentColor` の `1.8px`、`round` の端。塗りは「いいね済み」と「保存済み」だけ。
- アイコンは泡の中央に置く（アプリバー 24px / 店の欄・戻る・共有 20px）。
- 評価サイトはロゴを使わず頭の 1 字（食 / ぐ）。Google マップは単色の G。
- アイコンフォントと PNG のアイコンは使わない。

## 写真と絵

- ジャンルの顔は `img/faces/`（192px の絵）。無ければ絵文字。
- 店の写真は実物（公式サイト・口コミサイト）。一覧では角なしで敷き詰め、詳細の頭は `radius-8`。写真の上の札（★ 4.4 / おすすめ / 12 枚）は黒 .45 の `radius-pill` に白 11px 700。
- ロゴは `assets/Logos` の泡のロゴだけ。黒地の上にだけ置く。

## 写していないもの

- 3D の夜の街（MapLibre）と canvas で漂う泡・しぶきの動きは、プレビューでは静止した絵で示す。
- 写真の全画面・映画の予告編の再生・ベクトル地図の操作は写していない。
