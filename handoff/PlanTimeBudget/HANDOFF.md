# HANDOFF — PlanTimeBudget（web plan の「時間帯」と「予算」を決める 2 つの画面）

toopdbq.com のトップ = **渋谷の遊び方プラン**（3D の街の上にシャボン玉が漂う画面）。プランを頼むと、泡を押して答える
ヒアリングが進み、**時間帯**と**予算**だけは泡でなく**画面の中央に 1 つずつ出るダイアログ**で決める。
今の時間帯の画面（縦のスライダー）は**直感的でない**。予算は**スライダーをやめ、選んだ好みの店の値段から作る
最大 5 段を縦に並べてタップで選ぶ**方式にし、**ヒアリングの最後**（好みを選んだ後）に移す。
この 2 画面を設計してほしい。**時間帯 3 案・予算 3 案**。挙動・データ・配置の制約は下記で固定。

## これは何か（プロダクト文脈）

- 画面 = 3D の街（MapLibre・暗い街路図。端末がライトなら明るい街路図）の上に canvas のシャボン玉。中央の**大きな玉**がヒアリングの見出しを持ち、
  答えた項目は**その中の小さな玉**になる（押すと弾けて選び直し）。右下に 52 の泡のボタン（検索 / 保存）
- ヒアリングの順（新）: どんなお出かけ → 誰と（…）→ **時間帯（ダイアログ）** → 好みの段（何を食べたい？ / 何して過ごす？ / その後は？ = 泡をいくつでも）
  → **予算（ダイアログ・新しくここ）** → AI がプランを組む
- 予算を最後にする理由: **ジャンルで値段の相場が違う**（カフェ 1 人 ¥750〜1,500 / 焼肉 ¥5,000〜7,000 / 古着 1 点 ¥8,000〜30,000）。
  好みが決まれば**その店の実際の値段の分布**から段を作れる
- 決めた後: 中央の玉に 🕐「14:30〜翌0:00」/ 💰「ふつう」のような小さな玉が入り、押すと同じダイアログが**今の値入り**で開き決め直せる（裏を押すと閉じる）

## 固定（契約 — 破ると実装できない）

- 画面 402×874（`.phone`）。status bar 62 / home indicator 34。タップ範囲 **≥ 44**
- **板（カード・面）を置かない**。街の上に**中心ほど濃いスクリム**を敷き、その上に部品を直に置く:
  `radial-gradient(ellipse 70% 56% at 50% 50%, rgba(V,.9), rgba(V,.66) 50%, rgba(V,.1) 100%)`、V = `0,0,0`（ダーク）/ `255,255,255`（ライト）。
  文字色 = `#fff`（ダーク）/ `#08080b`（ライト）。**ダークとライトの両方で成立**させる（specimen は `prefers-color-scheme` で切替）
- **部品の語彙は「泡」**: 丸い部品は全て `bubble.webp` の輪 + `rgba(V,.18)` の面 + `backdrop-filter: blur(6px)`、中央にアイコン / 絵文字 / 数字。
  実装済みの寸法: 右下ボタン 52・ダイアログの絵 48・つまみ 34。白い塗りの丸・角丸の箱・リストの罫線は使わない（glass ≤ 6 形状 / 画面）
- **決定ボタン**: 幅いっぱい（≤ 352）・高さ 54・r14・`#f0cf6a` 地 / `#1d1503` 文字・16 w700・`box-shadow: 0 0 18px rgba(240,207,106,.3)`。
  押して閉じる。最初の設定は裏を押しても閉じない / 決め直しは裏を押すと閉じる
- フォント: `-apple-system, "Hiragino Sans", "Noto Sans JP"`、数字は tabular。見出し 18 w700・値 17 w700
- **スクリムの下に見えているもの**（触れない・隠してよい）: 中央の大きな玉（半径 ≈ 150・中心 x 201 / y ≈ 610）と見出し「時間と予算を決めてね」。
  右下の泡ボタン（x 334–386 / y 696–748 と 757–809）は**スクリムより上に残る** = その上に部品を置かない
- **時間帯**: 朝 **6:00 〜 翌 6:00** の 24 時間窓・**30 分刻み**・**最短 60 分**・始まりは **23:30 まで**。初期値 = 今（30 分へ切上げ）〜 24:00、
  23:00 以降なら 〜翌 6:00、6:00 前なら 6:00〜24:00。値の表記 `14:30〜翌0:00`（en `14:30 – 0:00 +1`）。出力 = 始まり / 終わりの分（6:00 = 360 … 翌6:00 = 1800）。
  **始まりと終わりの両方を決められる**こと。**ドラッグ必須にしない**（タップだけで決められる案を最低 1 つ）
- **予算**: 行 = **2〜5 段**（データで変わる）。縦に並べ**タップで 1 つ選ぶ**。最上段か最下段に「こだわらない」。段の中身は下の「段のデータ」。
  出力 = グループごとの上限 `budgets: { dinner: [0, 6000], bar: [0, 3000] }`（上限 0 = 上限なし）
- 実装は web（React + CSS、タッチ）。**`input[type=range]` を CSS で回す縦スライダーは Chrome で値が動かない**ので、DOM + pointer events で作れる形に。
  specimen は静的 HTML + 最小の JS（タップ / ドラッグで状態が変わる程度）でよい
- 文言（ja / en）: 何時から何時まで？ / What time? ・ 予算はいくらまで？ / What's your budget? ・ 決定 / Done ・ こだわらない / Any ・
  1 人 {amount}まで / Up to {amount} per person ・ 1 点あたり / per item。新しい文言は足してよい（短く・2 行以内）。絵文字は泡の中だけ

## 段のデータ（予算 — 実装がこう作る。specimen はその結果を描く）

- 値段を持つグループ = **カフェ snack / 昼 lunch / 夜 dinner / 夜の店 bar / 服 wear / 靴 shoes**（服・靴は 1 点あたり、ほかは 1 人あたり）。
  映画・カラオケ・名所・サウナなどは値段を持たない → 段に出さない。値段を持つグループが 1 つも無ければ予算の画面は**出ない**
- 選んだ好み（例: 焼肉・ビール）に当たる店の値段を**グループごと**に集め、**20 / 40 / 60 / 80 パーセンタイル**をきりのいい額に丸めて上限にする
  （¥2,000 未満 250 刻み / ¥6,000 未満 500 刻み / それ以上 1,000 刻み）。同じ額は 1 つにまとめる → **段は 1〜4 + こだわらない = 2〜5 行**。
  複数グループのときは **同じ段 = 同じパーセンタイル**（「ふつう」= どのグループも 40%）。段の名前（例: 気軽に / ふつう / ちょっと贅沢 / 贅沢）は Design が決めてよい
- 実データの例（渋谷のカタログ 4,023 店・括弧 = その上限までに入る店の数）:
  - A デート × 気軽に（イタリアン・カフェ・映画）: 夜 イタリアン 85 店 → 〜¥3,000(18) 〜¥4,000(36) 〜¥5,000(67) 〜¥6,000(81) / カフェ 319 店 → 〜¥750(59) 〜¥1,000(133) 〜¥1,250(229) 〜¥1,500(290) / 映画 = 値段なし → **5 行**
  - B 友達 4 人 × 遊ぶ（焼肉・カラオケ・ビール）: 夜 焼肉 113 店 → 〜¥5,000(41) 〜¥6,000(80) 〜¥7,000(94) / 夜の店 ビール 50 店 → 〜¥2,500(12) 〜¥3,000(29) 〜¥3,500(37) 〜¥4,000(48) / カラオケ = 値段なし → 焼肉は 3 段しか無い（40% と 60% が同額）→ **その段は空欄か前の段と同じ額**（Design が決める）
  - C 1 人 × 観光 食べ歩き（ラーメン・スイーツ・名所）: 昼 ラーメン 98 店 → 〜¥1,000(79) の **1 段だけ** / カフェ スイーツ 96 店 → 〜¥750(18) 〜¥1,250(52) 〜¥1,500(74) → **4 行**
  - D 古着 + カフェ: 服 古着 418 店 → 1 点 〜¥8,000(97) 〜¥12,000(191) 〜¥16,000(255) 〜¥30,000(348) / カフェ 319 店 → 上と同じ → **5 行**
- 行に出す情報の候補（取捨は Design）: 段の名前 / グループごとの上限額（1〜3 グループ）/ その上限までに入る店の数 / 店の写真の例（`assets/sample/` から）

## 今の画面の弱点（as-built から読めること）

- 時間帯: 縦の帯に同じ見た目のつまみが 2 つ → どちらが始まりか分からない。帯に**時刻の目盛りが無い**（6 時と翌 6 時の端しか分からない）。
  値は帯の下の文字でしか読めない。つまみの泡は帯の暗い部分で見えにくい。「今から」「夜だけ」のような**よくある決め方が 1 操作でできない**
- 予算: 1 本のスライダーで ¥1,000〜¥30,000 を同じ長さに置くので、ジャンルの相場と無関係な刻みになる（ラーメンに ¥30,000 の目盛りは要らない）

## 探索してほしいこと

- 時間帯（3 案・似た案を 2 つ出さない）: ①**1 日の縦の帯**に時刻の目盛りと帯の名前（朝 / 昼 / 夕 / 夜 / 深夜）、始まりと終わりの泡に時刻を内包 /
  ②**24 時間の円（アーク）**で範囲を弧として見せる（日の出 → 日没 → 夜） / ③**タップだけ**: よくある枠（今から / 昼 / 夕方〜夜 / 夜〜深夜）の泡 + ±30 分の微調整。
  どの案も「始まりと終わり」が一目で分かり、**今の値が常に読める**こと
- 予算（3 案）: ①段の名前 + グループ別の上限額を 1 行に / ②店の数を長さで見せる「はしご」 / ③各段に店の写真 2〜3 枚。
  行数 2〜5 で崩れないこと・1〜3 グループで額が読めること・選んだ行が 1 つだけ強調されること
