時間帯と予算を決める 2 つのダイアログ — 採用案

板を置かず、中心ほど濃いスクリムの上に泡の部品を直に置く。今の値が常に読め、選んだものは 1 つだけ強調。決定 → 答えの泡 → 押すと今の値入りで決め直し（裏を押すと閉じる）。各フレームはそのまま触れます。仕様は HANDOFF.md・brief。スマホでは app.html を開くと全画面で動きます。

採用

時間帯 = 縦の棒 + 棒で生えた から / まで の泡 + よくある 4 枠。予算 = 段の名前 + グループ別の上限。specimen の「今」は 14:12（初期値 14:30〜翌0:00）。

予算の行数 2〜5・桁の違うグループ

B = 焼肉は 40% と 60% が同額（薄く出す）/ C = ラーメンは 1 段だけ → 4 行 / D = 古着 1 点 ¥30,000 とカフェ ¥1,500 / E = ラーメンだけ → 2 行。

決め直し（答えの泡を押して開いたとき）

今の値が入った状態で開く。裏（スクリム）を押すと値を戻して閉じる。最初の設定では裏を押しても閉じず、決定の泡が小さく揺れる。
