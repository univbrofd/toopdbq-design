TimelinePlaceMode — motion

カーブは --ease-out = cubic-bezier(.16,1,.3,1)（as-built と同じ）。 地図パネルは高さ 0 → 437 を 360ms、サークルのフィードはx 0 → −100%、場所のタイムラインはx +100% → 0 を 440ms。 地図のカメラはサークルのエリアへ 500ms。変えたのは 2 つだけ: ピンの出方（stagger）と別ピン切替（カードの横移動）。

受け渡しの注: 値は as-built 準拠（360 / 440 / 500ms、--ease-out）。 追加したのは ピンの stagger 160ms / 40ms と カード移動 180ms・cross-fade 120ms の 2 本だけで、 どちらも Curves.easeOut / easeInOut の範囲内。バウンス・無限ループは使わない。
