# HANDOFF — MapFullPlaceCards（マップの全画面で、表示範囲の場所を 6 枚の OGP カードで）

home のマップを**全画面にして真上から見下ろしている状態**で、画面の**上の帯 200** と**下の帯 200** に
場所の OGP カードを **3 枚ずつ（計 6 枚）** 並べる UI を設計してほしい。カードは**正方形の写真 + その上に
オーバーレイで情報**（名前 / ジャンル / 営業ステータス + 営業時間 / 距離 / 評価）。**マップの場所ピンと
カードを線で結び**、どこにある店かが分かるようにする。どの 6 件を出すかは**マップ帯を 3×2 に分割し、
各セルの中心に最も近いピン**（上の行 → 上の帯、下の行 → 下の帯、同じ列のカード）。
挙動・データ・配置の制約は下記で固定。「カードの情報設計・線の描き方・帯の chrome との折り合い・状態」を探索してほしい。

## これは何か（プロダクト文脈）

- home = サークルのタイムライン。上に地図、下に投稿の一覧。**地図をピンチ / 域の外へ pan / 一覧を下へフリック**すると
  **地図が全画面**になり、**真上から見下ろす（pitch 0）**。今はその状態で「サークル名（域中心）」「active の白い光のリング」
  「表示範囲の場所ピン（写真タイル 36・密集は +N に集約）」が地図に貼られ、画面下に一覧が 200 覗く
- 場所 = 投稿に添えた Google マップのリンクを backend が解決した店。ピンをタップ → **場所モード**（全画面を解除し、
  その場所の投稿の一覧 + 吹き出しカード）。**全画面中は吹き出しカードを出さない**（今の仕様）
- この依頼 = 全画面中に「見えている場所」を **6 枚のカードで一覧できる**ようにする。ピンだけでは「何の店か」が分からない
  （写真タイルだけ）。カードで名前・ジャンル・営業・距離・評価が一目で分かり、線でピンと結んで位置も分かる

## 固定（契約 — 破ると実装できない）

- 画面 402×874（`preview/card.css` の `.phone`）。status bar 62 / home indicator 34。タップ範囲は最小 44pt
- **地図は画面全面**（真上・pitch 0・openfreemap liberty のライトな街路図）。帯のカードは地図の**上に載る**
  （帯は透明でも glass でもよい = カードの周りに地図が見えてよい）
- **上の帯 = y 0–200**（status bar の下 **62–200 = 138** が使える）。**下の帯 = y 674–874**（home indicator の上
  **674–840 = 166** が使える）。**マップ帯 = y 200–674（474）× 402**。**下の帯は今の一覧の覗き（白面 200）と同じ高さ =
  覗きをカード行に置き換える**（覗きは出さない）
- **3×2 の割当（実装がやる。specimen はその結果を描く）**: マップ帯を 3 列 × 2 行（セル 134×237）に割り、セル中心
  x {67, 201, 335} × y {318.5, 555.5}。候補 = **中心がマップ帯の中にあるピン**（帯の下に隠れるピンは候補にしない）。
  **1 つの場所は 1 枚だけ**（重複なし）。候補が 6 未満なら**そのセルのカードは空**。集約ピン（+N）は代表 1 件
  （タイルの写真の場所）として候補に入る。参考アルゴリズム = 全（セル, ピン）の画面距離を昇順に、セルもピンも未使用なら採用
  （greedy）。線が交差することはある（避けなくてよい）
- **ピンは今のまま**: 36×36 / r11 の写真タイル（`box-shadow: 0 2px 8px rgba(8,8,11,.35), 0 0 0 1px rgba(8,8,11,.08)`）、
  写真の無い場所は ink `#08080b` 地 + ピン glyph 16 白。集約バッジ = タイル右上に白地 `+N`（高さ 18・r9・11 w800 ink）。
  選択中 = 白枠 2.5 + scale 1.14。**新しいマーカー形状を発明しない**（線の始点をピンに足すのは可）
- **線**: ピン ⇄ そのカード。ライトな地図（灰ベージュ + 黄の幹線）の上でも、他のピン・サークル名の上でも読めること。
  **pan 中は毎フレームピンに追従**して描き直す = 直線か単純な曲線（複雑なパスは不可）
- **カード**: 正方形。写真フルブリード（場所の og:image。無い場所 = ink 地 + ピン glyph）。オーバーレイに
  **名前 / ジャンル / 営業ステータス + 営業時間 / 距離 / 評価**。**1 帯に 3 枚**が横に並ぶ = 同じ大きさなら **≤ 122 角**
  （左右 10・間 8）。大きさ・角丸・余白は帯に収まる範囲で Design が決める
- サークル名（15 w800 白 + 黒ハロー・域中心）と active のリングは今のまま地図に残る
- フォント Noto Sans JP（本文）/ Inter（数字）。絵文字なし。アイコンは `assets/icons/`、写真は `assets/sample/`
- glass 形状 ≤ 6 / 画面（`taste.md` の予算。カード 6 枚を全部 glass にするなら他に使えない）
- 実装は Flutter（挙動は Controller 側）。地図と場所ピンは WebView（DOM）、**カードと線は Flutter が地図の上に描く**
  （JS が毎フレーム各ピンの画面 px を Flutter へ流すので線は追従できる）。specimen は**静的 HTML + 最小の JS**
  （地図の初期化・ピン px からの線描画程度）

## 既存 chrome との衝突（決めてほしいこと①）

- **上の帯にはすでに 2 つ載っている**: 左上の**クエストラベル**（`クエスト: お題名`・15 白 + 影・y 68–112・
  開催中のお題があるときだけ）と右上の**投稿 FAB**（camera アイコン 28 / タップ 55・y 62–117）。3 枚のカードと重なる
  → この状態では隠す / 帯の外へ動かす / カードを避けて縮める、のどれか
- **下の帯 = 今の一覧の覗き**は「地図つきへ戻る」導線（タップ / 上ドラッグ）でもある。置き換えるなら**戻る手段**を用意する
  （中心の active 名タップは残る。下の帯の上ドラッグ / チップ / × 等）

## 出せる情報（データの棚卸し）

| 項目 | 例 | 備考 |
|---|---|---|
| 名前 | `TK NIGHTCLUB` / `のんべい横丁` / `キャットストリート` | 常にある。長い名前あり |
| 写真 | og:image 1 枚 | **無い場所もある**（ピンも glyph） |
| ジャンル | Places `primaryType` = `night_club` / `cafe` / `park` | **英語の type 文字列**。表示名（`ナイトクラブ`）は要変換。表示用の `primaryTypeDisplayName` は未取得（採用は提案でよい） |
| 営業ステータス + 営業時間 | `営業中 5:00 まで` / `営業時間外 20:00 から` / `24時間営業` / `営業時間は未取得` | 曜日別 periods から今の状態に畳む（深夜跨ぎあり） |
| 距離 | `368m` / `1.2km` | 現在地から。`AppFormat` = 数値 + 単位（半角） |
| 評価 | `4.5 (1,500)` | **無い場所もある** |
| 投稿数 / 最新投稿 | `3件の投稿` / `9/9` | 出してもよい（依頼には無い） |
| 詳細未取得（`detailsPending`） | — | **ジャンル / 営業 / 評価が全部無い**場所がある = 名前 + 距離だけ |

## 決めてほしいこと（探索の軸）

1. **カードの情報設計**: ~122 角に 名前 / ジャンル / 営業 + 時間 / 距離 / 評価 を入れる優先順位と段組み。
   何を文字にし何をチップ（● 営業中 / ★ 4.5）にするか。写真をどこまで見せるか（スクリムの濃さ・帯状か全面か）。
   最小の文字サイズ（11 以上が目安）
2. **線**: 太さ / 色（白 + 暗ハロー・ink・破線）/ 端点（ピンのどこから・カードのどこへ）/ ピンが線の上に来るか下か /
   カードとピンが近いとき・遠いときの見え方
3. **帯の chrome**: クエストラベル・投稿 FAB とカードの折り合い（①）と、下の帯の**戻る導線**（①）
4. **状態**: 写真なし / 詳細未取得 / 評価なし / 24 時間 / 深夜跨ぎ / 長い名前 / 空セル / 集約ピン（+N をカードにも出すか）/
   選択中のピン（場所モードの白枠）
5. **モーション**: pan で割当が変わるときのカードの差し替え（その場で cross-fade / スライド）と線の追従、
   全画面に入るとき（地図が 360ms で寝るのと同時にカードが現れる）
