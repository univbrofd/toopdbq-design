# HANDOFF — World3D：渋谷のナイトクラブの「ポイント」を 3D の街に立てる

アプリ（Toopdbq）が画面の背景に敷いている**実物の 3D マップだけ**を出すページ。新機能の 3D 世界を、
モックの絵ではなく**動く地図の上**で考えるために用意した。出すデータは**渋谷のナイトクラブ 20 件だけ**
（本番 DB の実データ）。開発用のモック（サークル・投稿・お題）は出さない。

- ページ: `World3D.html`（Claude Design のページ一覧の「World3D」）
- 直リンク: `https://media.toopdbq.com/design/world3d/World3D.html?v=0861fdab`
  （`?v=` は配信キャッシュ避け。古い版が出たら本体側で再生成した新しい `?v=` をもらう）
- 見た目の記録: `shots/points.jpg`（既定 = 夜 + 光の柱）/ `shots/photos.jpg`（店の写真）/
  `shots/wall.jpg`（既存のエリアの壁と同居）/ `shots/liberty.jpg`（昼）

## 依頼

**渋谷のナイトクラブ限定の 3D 世界をつくる。1 軒 = 1 つの「ポイント」として街に立てる。**
（機能名は未定。決まり次第ここに入る）

決めてほしいこと:

1. **ポイントの姿** — 今は素の光の柱（ピンク `#ff3e88` / 半径 7m / 高さ 60m の押し出し）。
   これは「点がそこにある」以上の意味を持たない仮の形。クラブの箱・音・混み具合のどれを立体で
   語るのかを決める
2. **密集の扱い** — 20 点が半径 580m に入る（道玄坂・円山町は 1 ビルに複数）。今は店名の pill が
   素直に重なる。まとめる / 寄ると分かれる / 遠いと 1 つになる、のどれか
3. **遠近** — 街の中（zoom 16〜17.5）と、引いた渋谷全体（zoom 14 前後）と、地球（zoom 6.4）で
   それぞれ何に見えるか。アプリは同じ 1 枚の地図をズームで行き来する
4. **選んだとき** — 今は素の情報カード（写真・ジャンル・営業時間・評価・住所）を仮に出している。
   これはデザイン対象
5. **夜と昼** — 主題が夜なので既定は dark。liberty（昼）でも成立させるか、夜に寄せるかを 1 行で

出力は `World3D.html` を Remix した新しいページ（案ごとに 1 ページ）。

約束:
- 実装に落ちる形で出す ＝ 下の「守る値」の範囲で、地図・壁・場所ピンと**競合しない**層に置く
- 色・文字は `DesignSystem/colors_and_type.css` のトークンを使う（アプリの色の正）
- 英字の見出しは全部大文字にしない（先頭 1 文字だけ）
- 常時動くアニメは端末の発熱の主犯。動かすなら操作中か、選んでいる 1 つだけ

## 中身と触り方

| 層 | 実体 | 触ってよいか |
|---|---|---|
| engine | `…/design/world3d/engine/*.js` = **アプリ実装の写し**（MapLibre の生成・カメラ API・エリアの壁・場所ピン） | ✋ 触らない（実装が正） |
| data | `…/design/world3d/data.js` = 本番 DB から抜いたナイトクラブ 20 件 | ✋ 手で書き換えない |
| page | `World3D.html` の `<style>` と末尾の host スクリプト | ✅ **ここに書く** |

`map`（MapLibre インスタンス）と `window.World3D`（`{state, data, area, map, applyPoints, …}`）が
グローバルに出ている。`map.addLayer(…)` の fill-extrusion / custom layer、three.js の custom layer、
DOM マーカー、いずれも足せる。

操作盤（左下）はサンドボックスの道具でデザインではない。`×` でしまえる。提案では消してよい。
URL クエリ: `?style=liberty&pitch=60&points=photo|pin|off&labels=0&wall=1&buildings=0&clubonly=1&framed=1&zoom=17&bearing=30&dim=.6`

## データ（`data.js`）

`window.World3DData = { area, station, clubs[20] }`。本番 RTDB の `placeDetails`（Google Places 由来）から
**渋谷駅 1500m 以内・渋谷区・Places の型が `night_club` / `dance_hall`・写真あり**を取り、
キャバクラ / ガールズラウンジ / カラオケ / シーシャを名前で外したもの。

| 使える値 | 中身 |
|---|---|
| `name` / `lat` / `lng` | 店名と位置（20 件すべて） |
| `imageUrl` | 店の写真（R2 配信。20 件すべて。中はほぼ実際のフロア写真） |
| `kind` | `club` 13 件（踊る箱）/ `lounge` 7 件（型で拾った夜の店）。操作盤の「クラブだけ」で絞れる |
| `genre` / `genreLabel` | Places の型（`night_club` / `lounge_bar` / `bar` …）と日本語ラベル |
| `rating` / `ratingCount` | 4 件だけ（ATOM 3.2/1083・BAIA 4.4/1155・S NIGHTCLUB 4.5/160 …）。**全件には無い** |
| `open` / `close` / `closeHour` / `overnight` | 営業時間。深夜営業とはっきり分かるのは 3 件 |
| `address` / `mapsUrl` / `distanceM` | 住所・Google マップ・渋谷駅からの距離 |

`area` = 20 点の重心と全点を含む半径（35.65961, 139.69888 / r=580m）。ページの既定カメラと
「クラブ街の壁」に使っている。

**数の偏りは正直に**: 評価と営業時間は揃っていない。それ前提の見せ方にするか、揃っている値
（位置・写真・ジャンル）だけで立てるかを選ぶ。DB 側には WOMB / VISION / contact / clubasia など
大箱がまだ無い（収集範囲外）。入れるなら本体側で場所の収集をもう一度回す。

## 守る値（実装の実値。ここから外れた案は実装に落ちない）

**カメラ**
- MapLibre GL JS 5.6.0 / 投影は globe / スタイルは openfreemap の `dark`（このページの既定）と `liberty`
- zoom の絶対域 −6〜18。街の中の構図は 16〜17.5、クラブ街全体は 15.8（このページの既定）
- pitch は実機では 2 段（0 / 55）。エリアにフォーカスしている間だけ 60。
  **60 が実効上限**（MapLibre の既定 maxPitch）。85 は engine の定数にあるが効かない
- pitch に応じて上パディングが入る（最大 = 画面高の 40%）。壁を出す間は呼び出し側が画面比で固定
  （このページは画面高の 23%）
- 実機の画面は 402×874、SafeArea は上 62 / 下 34、タップ目標は 44pt 以上

**3D ビル**
- `liberty` は style 標準の `building-3d`（`fill-extrusion`・minzoom 14・色 hsl(35,8%,85%)・不透明度 .8）
- **`dark` には fill-extrusion が 1 枚も無い**。夜の街を立てるなら同じ vector source から自前で足す
  （このページの `w3d-buildings`: 色 `#1c2029` / 高さ `render_height` / 不透明度 .9）
- ポイントの柱はビルと**同じ深度**で描かれる（手前のビルに隠れる）。常に見せたいなら別の層が要る

**エリアの壁（光のカーテン）— 既存の 3D ボキャブラリ**
- 真円を 56 分割した白単色（`#ffffff`）のカーテン。壁高 = `max(160m, 半径 × 0.39)`
- 縦フェード（下から 0–34%: α.66→.36 / 34–70%: .36→.14 / 70–100%: .14→0）+ 縦リブ
  （0–42%: α.16 / 42–80%: α.07）+ 地面のにじみ（半径比 .17 でα.3 / .045 でα.7）
- 深度テストを切って**常に最前面**。壁面の名前は円筒に沿って曲がり、手前を 36px/s で流れる
- 状態色: 通常 白 / 達成 `#7cc47f`（高さ 60%）/ 未所属 `#9aa1ab`（0.72 倍）

**場所ピン（アプリが既に持っている点の形）**
- 写真の角丸スクエア 36（地点が中心・選択時だけ白枠）
- `pin` は赤いマーカー 28×40（先端が地点）。番号を渡すと白地に数字のマーカーになる
- 出し入れは 1 件ずつ時間差で立ち上がる（`setPlacePins` の stagger）

**実装に戻すときの制約（発熱・メモリ）**
- 描画は端末の WebView。dpr は 2 で頭打ち・アンチエイリアス無し・タイルキャッシュ 8 枚
- 動画はアプリ全体で同時 5 本まで（うち装飾用 4）
