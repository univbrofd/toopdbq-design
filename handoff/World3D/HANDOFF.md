# HANDOFF — World3D：3D マップだけのページ（新機能の「3D 世界」を考える土台）

アプリ（Toopdbq）が画面の背景に敷いている**実物の 3D マップだけ**を出すページ。新機能で使う
3D 世界のビジュアルを、モックの絵ではなく**動く地図の上**で考えるために用意した。

- ページ: `World3D.html`（Claude Design のページ一覧の「World3D」）
- 直リンク（ブラウザでそのまま開く）: `https://media.toopdbq.com/design/world3d/World3D.html`
- 見た目の記録: `shots/liberty.jpg`（既定）/ `shots/dark.jpg`（夜）/ `shots/framed.jpg`（実機の枠）

## 中身と触り方

| 層 | 実体 | 触ってよいか |
|---|---|---|
| engine | `…/design/world3d/engine/*.js` = **アプリ実装の写し**（MapLibre の生成・カメラ API・サークルの壁・場所ピン・お題の文字） | ✋ 触らない（実装が正） |
| data | `…/design/world3d/data.js` = アプリのモックデータ（`assets/mock`）からの生成物 | ✋ 手で書き換えない |
| page | `World3D.html` の `<style>` と末尾の host スクリプト | ✅ **ここに書く** |

新しい 3D 表現は**ページの中**に書く。`map`（MapLibre インスタンス）と `window.World3D`
（`{state, data, map, applyAll, …}`）がグローバルに出ているので、`map.addLayer(…)` の
fill-extrusion / custom layer、three.js の custom layer、DOM マーカー、いずれも足せる。

URL クエリで初期状態を指定できる: `?style=dark&pitch=60&places=pin&circles=0&wall=0&quest=0&buildings=0&framed=1&zoom=17&bearing=30&dim=.6`

操作盤（左下）はサンドボックスの道具でデザインではない。`×` でしまえる。提案では消してよい。

## 守る値（実装の実値。ここから外れた案は実装に落ちない）

**カメラ**
- MapLibre GL JS 5.6.0 / 投影は globe / スタイルは openfreemap の `liberty`（既定）と `dark`
- zoom の絶対域 −6〜18。街の中の構図は 16〜17.5（このページの既定 16.4）
- pitch は実機では 2 段（0 / 55）。サークルにフォーカスしている間だけ 60。
  **60 が実効上限**（MapLibre の既定 maxPitch）。85 は engine の定数にあるが効かない
- pitch に応じて上パディングが入る（最大 = 画面高の 40%）。フォーカス中は呼び出し側が
  画面比で padTop を固定する（このページは画面高の 23%）
- 実機の画面は 402×874、SafeArea は上 62 / 下 34、タップ目標は 44pt 以上

**3D ビル**
- `liberty` は style 標準の `building-3d`（`fill-extrusion`・minzoom 14・色 hsl(35,8%,85%)・不透明度 .8）
- **`dark` には fill-extrusion が 1 枚も無い**。夜の街を立てるなら同じ vector source から
  自前で足す（このページの `w3d-buildings`: 色 `#1c2029` / 高さ `render_height` / 不透明度 .9）

**サークルの壁（エリアの光のカーテン）— 3D 世界の既存ボキャブラリ**
- 真円を 56 分割した白単色（`#ffffff`）のカーテン。壁高 = `max(160m, 半径 × 0.39)`
- 縦フェード（下から 0–34%: α.66→.36 / 34–70%: .36→.14 / 70–100%: .14→0）+ 縦リブ
  （0–42%: α.16 / 42–80%: α.07）+ 地面のにじみ（半径比 .17 でα.3 / .045 でα.7）
- 深度テストを切って**常に最前面**（3D ビル・ラベル・他の円より手前）
- 状態色: 通常 白 / 達成 `#7cc47f`（高さ 60%）/ 未所属 `#9aa1ab`（高さ 0.72 倍）
- 壁面のサークル名は円筒に沿って曲がる（白 w800・行高 = 壁高の 31%・弧は最大 288°・
  手前の面を 36px/s で右→左へ流れる・裏側は α.55 の鏡文字）

**地図上の他の要素**
- サークルの円は実機では**面も線も描かない**（`fillOpacity: 0` / `lineOpacity: 0`）。
  地図に出るのは**名前だけ**で、面を持つのはフォーカス中の壁ひとつ（操作盤の「円のリング」は
  比較用に α.08 / 線 α.4 で塗る）
- 場所ピン: 写真の角丸スクエア 36（地点が中心・選択時だけ白枠）/ `pin` は赤いマーカー 28×40（先端が地点）
- お題の文字: エリア中心の**上空**に浮く白フチ文字 + カウントダウン（壁が無いと置き場所が無い）

**実装に戻すときの制約（発熱・メモリ）**
- 描画は端末の WebView。dpr は 2 で頭打ち・アンチエイリアス無し・タイルキャッシュ 8 枚に絞っている
- **常時動くアニメは発熱の主犯**。動かすなら操作中か中心の 1 つだけにする
- 動画はアプリ全体で同時 5 本まで（うち装飾用 4）。3D モデル（GLB）は `data.js` の
  `posts[].glbUrl` に 15 件ある

## データ（`data.js`・渋谷）

案を作るときの約束:
- 実装に落ちる形で出す ＝ 上の「守る値」の範囲で、地図・壁・ピン・お題と**競合しない**層に置く
- 昼（liberty）と夜（dark）の両方で成立するか、どちらかに寄せるなら理由を 1 行添える
- 色・文字は `DesignSystem/colors_and_type.css` のトークンを使う（アプリの色の正）
- 英字の見出しは全部大文字にしない（先頭 1 文字だけ）

戻す経路: 出来たページ（＋その CSS/JS）を bundle で受け取り、実装側で `assets/web/earth/`
と Flutter の呼び出しに落とす。specimen を実装より後から直すことはしない。
