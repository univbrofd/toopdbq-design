# HANDOFF — PlaceRanking 作成フロー v2（地図 + 3 セクションのシート + 地図の上の確認モード）

プロフィールの「ランキング」タブの右下 FAB から入る**場所のランキング作成フロー**の、**見た目の格上げ**を頼みたい。
フローの骨格（全画面の真上の地図 / 上部のジャンル + 検索 / 下端の 3 セクションのシート / 同じ地図の上の確認モード）と
挙動は**現状のまま**（as-built を下に固定値で書く）。変えてほしいのは **4 つの面のデザイン**:
**(1) 詳細セクション (2) ランキング調整セクション (3) リストセクション (4) 確認モード（最終画面）**。
方向性は「地図の上に**写真のスタックとステッカー風ラベル**が散らばる、遊びのある旅の記録アプリ」（下の参考デザイン）。
加えて **(5) 選んだ場所に自分の写真を追加で投稿できる導線**を新しく設計してほしい（場所ごとに思い出の写真が最大 3 枚、
スタックの素材になる）。

## これは何か（プロダクト文脈）

- 投稿には Google マップのリンクを 1 本添えられ、backend が**場所**（店）に解決する。ランキング = **タイトル + ジャンル +
  順位つきの場所（3〜10 件）+ 場所を囲む域**。1 人が何本でも作れる（例: 「渋谷で踊るなら」「道玄坂で朝まで」）
- 作成フローは**サークルに縛らず、今の地図の表示範囲を検索**して場所を集める（ジャンル一致 + キーワード）。
  ヒットは赤いマーカー、ランキングに入れた場所は白い番号のマーカー
- **選んだ場所には自分の写真を追加で投稿できる**（新規）。その場所への自分の投稿画像 = 「思い出の写真」で、場所ごとに最大 3 枚を
  スタック（重ねた写真）の素材にする。写真が 1 枚（場所の代表写真）しか無い場所もある
- 保存後はプロフィールのランキングタブに並び、詳細（専用の地図 + 順位の行）で見る。詳細は今回の範囲外

## 参考デザイン（言葉で捕捉。この空気に寄せる）

Moments（旅の記録アプリ）のマップ画面。**明るい真上の地図の上に、思い出がステッカーのように散らばる**:

- **写真のスタック**: 1 つの場所 = 白い縁の写真（ポラロイド風・角丸小）を 2〜3 枚、少しずつ回転させて扇状に重ねる。奥の写真ほど傾く。
  スタックの左上に**日付バッジ**（赤い帯に月 + 白地に大きな日 = 「MAY 25」のカレンダー風）、右上に**件数の丸バッジ**（「87」「2」）
- **ラベル**: スタックの手前に**太い斜体の大文字をベタ塗りの帯に載せたステッカー**（「PLACE OF POWER」= 青紫の帯 / 「SUNSET」=
  オレンジの帯 / 「WAL…」= ピンクの帯）。少し回転して貼ってある。帯の色は場所ごとに違う
- **人**: スタックの下端に**行った人のアバター 2〜3 個**が重なって並ぶ
- **切り抜きのステッカー**（自由の女神・ヤシの木）が写真から飛び出す = 遊び。地図の他の場所は小さな**丸い写真ピン**
- **上端**: 中央に大きな都市名「NEW-YORK」（太い斜体・白地に黒の縁取り・少し傾く）。ナビは メニュー / 「Moments」/ 検索 / アバター
- **下端**: 中央に **「+ New Moment」の濃い青紫のピル CTA**（白文字・太字）
- 全体: 地図は淡い（水色の川・薄いグレーの街区）、要素は高コントラスト・大きめ・重なり上等。**「整った UI」より「貼った感」**

## 固定（契約 — 破ると実装できない）

- 画面 402×874（`preview/card.css` の `.phone`）。status bar 62 / home indicator 34。タップ範囲は最小 44pt
- **フローの骨格はそのまま**: 全画面の**真上（pitch 0）の明るい地図**（openfreemap liberty）が下地。地図は 1 本指 pan / ピンチ可。
  上部 chrome = 左上の戻る + ジャンルのチップ + 検索欄（+ 地図を動かした後の「この場所を検索」）。下端 = 1 本の
  `DraggableScrollableSheet`（白）に **3 セクションを縦に並べ、直前の操作に関わるセクションが先頭**（検索 → リスト /
  マーカー・カード・箱の要素のタップ → 詳細 / ランキングに入れた → ランキング。残りはそれまでの順）。シートの高さは
  中くらい 0.45 → スクロールで 0.8、地図を触ると短く（1 枚分）、短いところから引き下げると閉じる。
  **「作成」はランキングのセクションの下**。押すとシートが画面の下まで滑って閉じ、**同じ地図の上の確認モード**へ
  （角度は変えない）。確認モード = 上位 3 件の三角形の中心を画面の中心に置き、その地点に写真のスタック。上端にタイトル、下端に保存
- 上部 chrome の見た目（戻る / チップ / 検索欄）は**変えなくてよい**（変えるなら差分だけ）。変えてほしいのは下の 4 面 + 追加投稿の導線
- **明るい地図の上の chrome は白文字 AA を保つ**（暗い面 `--lg-tint-dark` か、白い面に ink）。glass 形状 ≤ 6 / 画面、
  リストのセルに glass 禁止（`taste.md` の予算）。ステッカー風の要素は glass ではなく**不透明の面**で
- フォント Noto Sans JP（本文）/ Inter（数字・順位）。**ジャンルのチップだけ絵文字を先頭に付けている**（既存・そのまま）。
  それ以外に絵文字は使わない。アイコンは `assets/icons/`、写真は `assets/sample/`（`reel/` `user/` `background/`）
- 実装は Flutter（挙動は Controller 側）。specimen は**静的 HTML + 最小の JS**（地図の初期化程度）。地図の上の要素は
  地点の投影 px に Flutter が置く（JS は何も描かない）ので、specimen では地図の上に絶対配置でよい

## 探索してほしいこと

1. **確認モード（最終画面）**: 参考デザインの空気で。スタック（3 枚まで・1 位が最大）/ 順位 + 名前のステッカー風ラベル / 日付バッジ
   （最初に投稿した日 or 最新）/ 件数バッジ（写真の枚数 or 投稿数）/ 自分のアバター の組み合わせと大きさ。タイトルの見せ方
   （「NEW-YORK」のような太い斜体の縁取り文字にするか、今の白 + 影のままか。**写真の上の文字は影だけに頼らず面かスクリムで**）。
   「保存」を「+ New Moment」のようなピル CTA にするか。**4 位以下の見せ方**（小さな丸い写真ピン？ 何も出さない？）。
   状態: 1 件だけ / 3 件が近くて重なる / 写真が代表 1 枚だけ / 長い店名 / 保存中
2. **(1) 詳細セクション**: 上の情報（評価・営業状態・住所・営業時間）を保ちつつ、**思い出の写真 3 枚 + 「写真を追加」の導線**を主役にする。
   追加 = カメラ / ライブラリ（既存の投稿フローと同じ入口でよい）。追加した写真がスタックに入る様子、3 枚を超えたときの入れ替え、
   削除。「ランキングに入れる / 外す」の丸ボタンの置き場と重み。× の扱い
3. **(2) ランキング調整セクション**: 横並びのドラッグで順位を決める挙動は固定。列の見た目（丸い写真 → 小さなスタック？ 順位の
   ステッカー？）、タイトルの編集の入口（下線リンク → 別の形でも）、「作成」CTA の重み（ink の面 / colorful グラデは最重要 1〜2 箇所限定）
4. **(3) リストセクション**: OGP カード（写真 + 名前 + 住所 + 右端のチェック）を、ステッカー感を少しだけ足して整える。
   評価順だが評価は見せない。**リストのセルに glass は使わない**
5. **セクションの区切り**: 見出し無し + 8px の帯 が今。3 セクションが入れ替わっても迷わない区切り方（帯 / 見出し / 色）
6. **モーション（言葉で）**: セクションの先頭が入れ替わるとき、シートが下へ滑って確認モードへ移るとき、スタックの入場
