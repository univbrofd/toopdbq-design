プロフィールに 3 つ目のタブ「ランキング」を足し、右下の追加 FAB から home と同じ地図を全面に敷いた作成フローへ遷移する。 固定（タブ行 44・ライト面・402×874・真上 pitch 0・暗い chrome・名前 / 円 / 白い光のリングの 3 要素）は動かさず、 A. 一覧の形と FAB を 3 案、B-1. サークル選択の確定のさせ方 を 3 案、B-2 以降 は推し案の手順を 1 本通しで置いた。 地図は MapLibre（openfreemap liberty）を真上で。ranking-map.js がサークルの数だけ円を描き、名前は 64px で「代表名 +N」に集約する（pan / ピンチ可）。

推しA2 + B1-b、手順は 3（選ぶ = 順位 → 並べ替え → タイトル・保存）
一覧の情報の優先順位 — タイトル（16 w700・主役）> 1 位の写真 > 順位 + 店名 > サークル chip · 件数 · 日付 > 住所。自分の投稿サムネは行から外した（店の写真と二重になり、主役が割れる）。 A1 は 5 本を超えると 1 画面に 1 本も入らず、A3 は住所も件数も無いので「どの店か」を写真の記憶に頼る。A2 は 1 本の高さがほぼ一定（≈ 380）で流し読みでき、開けば全件になる。
  1. FAB の重み — colorful の Ø56。プロフィールに colorful は他に無く、home の投稿 FAB と同じ「作る」の意味を持たせられる。スクロール中も残す。他人のプロフィールでは出さない。
  2. サークル選択の確定 — B1-b の「選択 → 下端カード → CTA」。円は半径 500〜600m で重なるので、即決（B1-a）は誤タップの戻りが増える。カードに自分が投稿した場所の数を出せば、 0 のサークルを選んだときも「候補はサークルの場所から」と先に伝えられる。帯（B1-c）は逃げ道として良いが、下端を隠して地図が全面である意味が薄れる。
  3. 手順の数 — 4 → 3。場所のタップ順を順位にするので「順位を決める」は直す画面になり、迷わない人はそのまま次へ。タイトルは最後（並べ終わってから言葉が出る）。空欄なら仮タイトルで止めない。
  4. glass 予算 — 全画面で × の 1 つだけが glass（B1-c のみ 3）。シートは as-built の opaque（rgba(10,10,14,.9)）で白文字 AA を面で担保。リストの行に glass は無い。
