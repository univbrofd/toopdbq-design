まとめ確認モード + 詳細 S3。主役 = 写真のスタック、効果の予算は「面 + 影」の 1 群に集約
何を主役にしたか — 4 面とも白い縁の写真。リストの写真（88×66・±2°）→ 箱のミニスタック（64・3 枚）→ 確認モードのスタック（150 / 118 / 92）と、同じ物が縮尺を変えて現れる。 順位は常に 白地に ink の「1st」のステッカー（写真の左上）、名前も白地に ink。確認モードに色は無い（ジャンルの色は選択中のチップだけ）。
  1. 確認モードは 16:9 の行配置 + 左上の順位 + 名前の帯。写真を横長にして順位ごとに 1 行を使う — 1 位は幅いっぱい、2・3 位は空いている上下へ。同じ高さに他の順位を置かないので、どんな位置関係でも重ならない（3000 ケースで 100%）。帯は店名を写真の幅から解放し、タイトルは白地 + ink の輪郭 6px。地図の上に出すのは 写真 / 重なり / 順位 / 名前 の 4 つだけ。4 位以下は丸い写真ピン 36。
  2. 詳細は写真の 3 枡が主役。「写真を追加」は説明文ではなく空いている枡そのもの。16:9 の代表写真は 1 枡目に吸収。追加はスタックへ即反映するので「何のために足すか」が見える。
  3. 効果の予算 — ステッカー = 白縁 + 影の 1 群（縁取り・グロー無し）。チップ = 面 + 影の 1 群（as-built の 面 + 縁 + glow を 3 → 2 に）。glass = 戻るの 1 つ / 画面。シート・帯・バッジは全部不透明。
  4. CTA の作法 — シートの中の「作成」「決定」は ink の面のピル（56 / 44）。地図の上の「保存」は白地 + ink の枠のピル 56（白いステッカー群と同じ材質）。透けた白は廃止。colorful グラデはこのフローで使わない（プロフィールの FAB が入口として持っている）。
  5. 区切り — 8px の帯 + セクションごとに違う見出しの形（eyebrow / 下線フィールドのタイトル / 店名 + ×）。同じ強さの見出しが並ばないので、先頭が入れ替わっても迷わない。
モーション（言葉で）
  • 先頭のセクションが入れ替わる: 先頭に来るセクションは高さ 0 → 実高さへ 240ms --ease-out で開き、中身は 12px 下から fade。元の先頭は同じ 240ms で下へ押し下げられる（消えない）。シートの高さは変えない。
  • 「作成」→ 確認モード: シートが 320ms --ease-standard で画面の下へ滑る。同時に地図が 3 件の重心へ 480ms で寄る（角度は変えない）。マーカーの白い順位はその場で白いピルへ形を変えて（120ms）ラベルの「1st」になる。
  • スタックの入場: 地図が止まってから 1 位 → 2 位 → 3 位の順に 60ms ずらし、各スタックは地点の位置から行の位置へ 260ms --ease-out で滑る（scale .9 → 1 + fade）。奥の 2 枚は正面から扇状に開く（回転 0 → +2.5° / −3°、同じ 260ms）。点線はスタックが着いてから 120ms で伸びる。順位のステッカーは着地で pop（scale .6 → 1・120ms）、帯はその後 80ms 遅れて左から出る。
  • 写真を追加: 投稿フローから戻ると、その枡に写真が fade 200ms で入り、右の列のミニスタックに 1 枚増える（+7° へ開く 180ms）。
