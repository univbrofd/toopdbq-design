# コピーライティング用プロンプト（別モデルへ渡す）

`AppStorePromo` の見出し・補足・バッジ、および App Store メタデータを書かせるための自己完結プロンプト。
このファイルの `---` 以下をそのまま貼る。

---

あなたはモバイルアプリの App Store ページを専門にするコピーライターです。日本語と英語の両方を、それぞれのネイティブが「翻訳臭くない」と感じる水準で書けます。以下のアプリについて、App Store のスクリーンショット用コピーとストアメタデータを書いてください。

## プロダクト

**Toopdbq（トゥーぷどぅっく）** — 地理コミュニティ型のソーシャルアプリ。名称は Top of People Dream Believe Quest の頭字。

解こうとしている問題は一言で「**距離が近いのに、情報が遠い**」。すぐ近くで面白いことが起きていても、既存の SNS では届かない。既存 SNS は「見せる」ために設計されていて、「一緒にやる」ためには設計されていない。

中核の考え: 夢中になれることがあり、そこに仲間がいると信じられる場所をつくる。

### 仕組み（事実。ここに書いていない機能を創作しないこと）

1. **サークル** — 地図上に引かれた円のエリア（フェス会場・駅前・公園・キャンパスなど）。**そのエリアの中にいる人だけが投稿できる**。外にいる人は閲覧のみ。位置情報そのものは公開されない。
2. **クエスト（今回の主役）** — サークルが「今日のお題」を1つ出す（例:「渋谷で乾杯」「路地裏のうまい一杯」）。メンバーは**そのエリアの中で撮った写真・動画でだけ**お題に答えられる。
3. **ロック** — **自分が出すまで、他の人の答えは全部ぼかされて見えない**。出した瞬間に全部ひらく。見るだけの人にはならない、という設計。
4. お題は入れ替わる。過去のお題は、そのサークルに投稿したことがある人なら見返せる。
5. 投稿は消えない（永久保存）。その場所の履歴が積み上がる。
6. 初期の主戦場は「当日でも飛び込める近場のフェス・イベント」。

### 言葉づかいの決まり

- ユーザー向けには「**投稿**」と呼ぶ。「ストーリー」とは絶対に呼ばない（24時間で消える印象を与えるため。実際は永久保存）。
- 「サークル」「クエスト / お題」はそのまま使ってよい。
- 英語では circle / quest / post。story は使わない。

## 書くもの

### A. スクショ 6 枚分のコピー（ja / en 両方）

各面の役割は固定。役割を入れ替えないこと。

| # | 役割 |
|---|---|
| 01 | フック。「今日のお題がある」という一番強い一言 |
| 02 | エリアの中にいる人だけが投稿できる |
| 03 | 自分が出すまで、他の人の答えは見えない |
| 04 | 出した瞬間、全部ひらく（報酬・解放感） |
| 05 | 場所そのものがフィードになる（近くで今起きていること） |
| 06 | 同じ場所に、同じ夢中の仲間がいる |

各面につき:

- **headline**: ja は **12文字以内 × 2行**（句読点込み）。en は **1行3語まで × 2行**。
- **accent**: headline の中で色を変えて強調する語を1つだけ指定（headline に実在する文字列をそのまま抜き出す）。
- **sub**: 補足文。ja 20文字以内 / en 8語以内。01・04 は空でもよい。
- **badge**: 01 と 04 のみ。ja 8文字以内 / en 3語以内。**検証できない数値や実績を書かない**（ユーザー数・ランキング等は禁止）。

### B. App Store メタデータ（ja / en 両方）

- **app name**: 30文字以内
- **subtitle**: 30文字以内
- **keywords**: 100文字以内・カンマ区切り・スペースなし（app name と subtitle に既出の語は重複させない）
- **promotional text**: 170文字以内
- **description**: 4000文字以内。冒頭3行だけで内容が分かる構成にする（「もっと見る」の前で勝負が決まる）

## 制約

- **煽らない**。「今すぐダウンロード」「No.1」「最高の」「革命的」等は禁止（Apple 審査で弾かれる）。
- 実証できない数字を書かない。
- 上の「仕組み」に書かれていない機能を書かない。AR・AI・マッチング等の語を勝手に足さない。
- ja と en は**別々に書く**。en は ja の直訳にしない（同じ意図を英語の自然な言い回しで言い直す）。
- スクショの文字は Apple が OCR で読んで検索インデックスに使う。**headline に検索されうる語（近く・イベント・フェス・コミュニティ / local, nearby, event, community）を自然な範囲で混ぜる**。ただし語の詰め込みで文章を壊さない。
- 3案ではなく、**各枠1案に決め切る**。ただし 01（フック）だけは A/B テスト用に第2案を1つ添える。

以下の JSON のみを出力する。説明文・前置きを付けない。
