Toopdbq App Baseline

アプリの「今」。一次情報は Flutter 実装（repo univbrofd/toopdbq master）で、shots はその実機撮影（iPhone 17 sim・mock データ）。このページは閲覧専用の起点 — 新しい機能を考えるときはまずここで現状を掴み、対象画面の canonical specimen を Remix して始める。このページ自体は編集しない（実装が進んだらアプリ側の再基準化で更新される）。

最終再基準化 2026-08-22 (5) 実装 05e361a7 + 作業ツリー 正 = Flutter 実装（このページ ＞ 過去の specimen / handoff）

DESIGN CYCLE

  1. ここ（Baseline）で現状を掴む
  2. canonical specimen を Remix して発想（雑で OK）
  3. bundle / project URL をアプリへ /import-design-bundle
  4. Flutter へ具現化 /design-to-flutter
  5. 実装が確定したら /design-baseline で再基準化（このページが更新される）

実装確定後に specimen へ逆修正はしない（drift 源）。ズレは次の再基準化で「実装が正」として吸収する。

Home = クエスト（主画面）

実装は lib/feature/Universe/。起動はクエストフィード直起動（「エリア内 × 開催中のお題」で投稿数最多のサークルを先頭に。旧「おすすめ」起動画面は廃止）。home はフィード拡大が既定で、マップパネルは縮小トグルで開く。マップパネル＝域リング内にサークル名・お題＋残り時間はマップ上部・投稿カメラは右上（エリア外は「エリアまで N km」ピル）。縦スクロール＝サークル切替、横レール＝投稿（いいね順⇄新着順の双方向無限・いいね数はセル右上）。未達成お題は blur ロック、日単位で解錠（member は過去日閲覧可）。

アプリの画面だけ page（app/）

タイトル・説明などの chrome を一切持たない画面そのものの page 群。実装同等のインタラクション付き（フィード操作・シート・入力）。Remix はここから始めると余分な要素が混ざらない。
